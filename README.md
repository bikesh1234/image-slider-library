# Nepal Image Gallery

A simple image slider made with HTML, CSS, and JavaScript. It includes Nepal-inspired landscape photos, plain previous/next arrow buttons, and dots to select an image.

## Run the website
1. Extract the ZIP file.
2. Open `index.html` in a web browser, or open the folder in VS Code and use Live Server.
3. An internet connection is needed to load the photos.

## Files
- `index.html` — page structure
- `style.css` — simple layout and normal arrow buttons
- `slider.js` — image navigation
